runlog — PRD

Draft · written by the Planner · 2 min ago

Problem

I run three times a week and forget how each run went. Apps like Strava are made for sharing, not for a quick private note after a run.

Goals

  • Log a run in under 15 seconds, one hand, on the phone.
  • See this week against last week: distance, time, pace.
  • Data stays on the phone. No account.

Not in v1

  • Strava and watch import (planned for v2).
  • Maps, routes, heart rate.
